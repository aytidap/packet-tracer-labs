# Packet Tracer Labs

Collection of networking labs and learning projects.

## About

This repository contains hands-on networking labs, experiments, and mini projects built while learning networking concepts and infrastructure technologies.

The labs cover topics such as switching, routing, VLANs, dynamic routing protocols, network services, security, and enterprise-style network implementations.

## Topics Covered

### Fundamentals

* IPv4
* IPv6
* Cisco CLI Basics

### Switching

* VLAN
* VLAN Trunking
* VTP
* Spanning Tree Protocol (STP)
* EtherChannel
* Port Security
* Layer 2 Switching
* Layer 3 Switching

### Routing

* Static Routing
* RIP
* EIGRP
* OSPF
* BGP
* Route Redistribution
* NAT

### Network Services

* DHCP
* DNS
* HTTP
* FTP
* SMTP
* VoIP

### Security

* Firewalls
* ACL
